1. Qué cambió

Antes se cargaban los dos montos siempre juntos — ahora primero elegís cómo cobraste

Hasta ahora, el modal “Registrar Pago” mostraba Monto Efectivo y Monto Transferencia siempre juntos, uno al lado del otro. Con la actualización:

Elegís primero la forma de pago

Tres botones: Efectivo, Transferencia o Mixto. El campo (o los campos) que corresponden recién aparecen después de elegir uno.

Las transferencias ahora piden un código

Si hay algo cargado en Transferencia, tenés que ingresar los últimos 5 caracteres del número de operación del comprobante (el que te da la app del banco o Mercado Pago al confirmar la transferencia).

Por qué se agregó esto

El código deja un rastro verificable de cada transferencia — evita que dos pagos distintos se carguen con el comprobante de una sola transferencia real, y le da a tu supervisor algo concreto para cotejar en Rendiciones.

💵

2. Cómo registrar un pago ahora

Mismo botón “Cobrar” de siempre — un paso nuevo antes de cargar el monto
Tocá “Cobrar” en la tarjeta del cliente, como siempre

Se abre el modal “Registrar Pago” con los datos de la cuota. Ahora, debajo, ves “Forma de Pago” con tres botones — todavía sin ningún campo de monto visible.

Elegí Efectivo, Transferencia o Mixto

Recién al tocar uno de los tres botones aparece el campo que corresponde.

Completá el/los monto(s)

Si elegiste Mixto, aparecen los dos campos — repartí el total entre Efectivo y Transferencia como corresponda.

Si hay transferencia, cargá el código de operación

Ingresá los últimos 5 caracteres (letras y/o números) del comprobante. El sistema los pasa a mayúsculas solo.

Confirmar Pago, igual que siempre

Queda pendiente de aprobación de tu supervisor, como antes.

🔑

3. El código de operación, en detalle

5 caracteres, únicos en todo el sistema, solo cuando cobrás por transferencia
Reglas del código
  • Obligatorio solo si cargaste algo en Monto Transferencia (efectivo puro no lo pide).
  • 5 caracteres, letras y/o números — el sistema los pasa a mayúsculas automáticamente mientras escribís.
  • Único en todo el sistema: si otro cobrador (o vos mismo en otro pago) ya usó ese código y sigue pendiente de aprobar o ya fue aprobado, el sistema lo rechaza.
  • Si un pago se rechaza en Rendiciones, su código queda libre automáticamente — podés volver a usarlo si era un error de carga.
  • Esto no aplica a admin/supervisor cuando cargan un pago directo desde la ficha del crédito.
✓ De dónde sale el código

Es el número de operación / comprobante que te muestra la app del banco o Mercado Pago al confirmar la transferencia recibida — tomá los últimos 5 caracteres de ese número.

⚠️

4. Si el código no es válido

Un aviso grande y centrado — no vas a poder confirmar el pago hasta corregirlo

Si el código tiene menos de 5 caracteres, o ya fue usado en otro pago, el sistema no deja confirmar y muestra un aviso rojo bien visible arriba de la pantalla:

Qué hacer

Revisá el comprobante y volvé a escribir los últimos 5 caracteres. Si estás seguro de que el código es correcto y el sistema igual lo rechaza por duplicado, avisale a tu supervisor — puede ser que ya lo hayas cargado vos mismo en otro pago por error.

❓

Preguntas frecuentes

¿Puedo cambiar de forma de pago después de elegir una?

Sí, tocá otro botón (Efectivo / Transferencia / Mixto) las veces que quieras antes de confirmar — los campos se ajustan solos.

¿Qué pasa si cobro todo en efectivo?

Nada cambia para vos: elegís “Efectivo”, cargás el monto y confirmás — no se pide ningún código.

¿El código se guarda igual si el pago se divide en varias cuotas?

Sí. Si con una sola transferencia se cubren dos o más cuotas atrasadas del mismo crédito, el código se guarda una sola vez — no hace falta repetirlo.

¿Y si me equivoco de código y ya confirmé el pago?

Avisale a tu supervisor: si rechaza el pago en Rendiciones, el código queda libre y podés volver a cargarlo correctamente.
